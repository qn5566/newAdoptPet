# 寵物領養紀錄

`index.html` 是 GitHub Pages 落地頁，提供 App 介紹、實際畫面和 iOS／Android 下載連結。

`app.html` 保留原本的手機平台下載轉址。`setting.json` 是 App 參數設定檔案。

展示圖位於 `res/store_screenshots/`，來源是 `res/screenshot/` 的最新介面。

發布 GitHub Pages 時，請一併提交 `index.html`、`style.css` 與 `res/store_screenshots/google_play/` 的圖片；首頁會從這些相對路徑載入素材。
