# 寵物領養紀錄｜商店完整說明

遇見想帶回家的毛孩，也好好記下牠成為家人的每一天。「寵物領養紀錄」把領養資訊與養寵日常放在一起，從尋找有緣的狗狗、貓咪，到整理照片、健康與花費，都能用一個 App 慢慢照顧。

【尋找有緣毛孩】
瀏覽等待領養的狗狗與貓咪，依條件篩選，查看照片、基本資料與收容資訊。遇到心動的毛孩，可以先收藏，之後再回來仔細認識牠。也能留意走失寵物資訊，幫牠多一分回家的機會。

【記錄牠的照片與生活】
為自己的寵物建立資料，保存照片與日常紀錄。從剛相遇的模樣，到一起生活的點滴，讓回憶有個地方可以整理。

【體重變化一目了然】
記下每次量測的體重，透過曲線查看變化，持續關心毛孩的成長與健康狀態。

【看診紀錄與提醒】
整理看診紀錄，設定看醫生提醒，讓重要的照顧行程更容易記得。

【掌握寵物花費】
記錄醫療、用品等日常支出，查看花費總覽、分類比例與趨勢。清楚知道錢花在哪裡，也更方便安排之後的照顧預算。

無論你正在尋找新的家人，或已經和毛孩一起生活，「寵物領養紀錄」都陪你把每一次相遇、每張照片和每個照顧牠的日子，好好留下來。
