# 寵物領養紀錄 WordPress 頁面 SEO 設定

新增一個「頁面」，並將 `adopt-pet.html` 放在頁面內容的自訂 HTML 區塊。頁面標題通常會由主題顯示為 H1，嵌入區塊使用 H2 開始，避免重複 H1。

## 頁面欄位

頁面標題：寵物領養紀錄 App｜尋找有緣毛孩，記下相伴日常

網址代稱：pet-adoption-record

頁面摘要：認識等待領養的狗狗與貓咪，留意走失寵物資訊，收藏喜歡的毛孩，記下與牠相伴的每一天。

## Yoast SEO 或 Rank Math 欄位

主要焦點關鍵字：寵物領養紀錄

其他自然相關詞：寵物領養 App、狗狗領養、貓咪領養、走失寵物、寵物體重紀錄

SEO 標題：寵物領養紀錄 App｜領養毛孩與生活紀錄

Meta 描述：用寵物領養紀錄尋找待領養的狗狗與貓咪，依條件篩選並查看收容資訊。也能留意走失寵物、收藏喜歡的毛孩，記下體重與看診紀錄。立即下載 iOS 或 Android 版。

社群分享標題：寵物領養紀錄｜遇見有緣毛孩，記下相伴日常

社群分享描述：從尋找等待家的牠，到記錄相伴的日子。下載寵物領養紀錄，為每份相遇多留一點溫柔。

社群分享圖片：上傳本目錄的 `seo-social.png`，並在 Facebook／Open Graph 和 X／Twitter 圖片欄位選用。

## 發布前確認

- 頁面設為公開，SEO 外掛不要勾選 `noindex`。
- Canonical URL 使用發布後的 WordPress 頁面網址，不要填 GitHub Pages 網址。
- 將此頁加入網站選單，並從一篇相關的領養或寵物文章連結過來。
- 頁面上架後，將網址提交至 Google Search Console 索引檢查。
- 確認 App Store、Google Play 按鈕以及六張畫面圖片都能正常開啟。
